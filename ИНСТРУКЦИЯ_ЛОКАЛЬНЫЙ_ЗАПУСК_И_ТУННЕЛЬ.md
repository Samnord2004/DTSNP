# Инструкция по запуску ДТСН «Пенсионер» GIS на локальном компьютере и через туннель

Данное руководство описывает, как запустить приложение на локальном компьютере под управлением **Windows (10/11)** или **macOS (Apple Silicon M1/M2/M3/M4 и Intel)**, а также как опубликовать его в интернет через **туннель** (Cloudflare Tunnel, Localtunnel, ngrok), чтобы другие члены правления, председатель и собственники могли открывать его по ссылке с телефона или ноутбука без белого IP и проброса портов.

---

## 1. Подготовка (один раз)

На компьютере должен быть установлен **Node.js** (рекомендуется версия 18, 20 или 22 LTS).
- Если Node.js ещё не установлен, скачайте его с официального сайта: [https://nodejs.org/](https://nodejs.org/) (установщик для Windows `.msi` или macOS `.pkg`).
- Проверить установку можно в терминале/командной строке:
  ```bash
  node -v
  npm -v
  ```

---

## 2. Быстрый запуск в 1 клик

### Для Windows:
Просто дважды кликните по файлу **`start-windows.bat`**.
Скрипт автоматически:
1. Проверит наличие Node.js;
2. Установит зависимости (`npm install`), если это первый запуск;
3. Соберёт production-билд (`npm run build`);
4. Предложит меню:
   - `[1]` — Обычный запуск на `http://localhost:3000` (откроет браузер);
   - `[2]` — Запуск с автоматическим туннелем **Cloudflare** (выдаст публичную ссылку вида `https://...trycloudflare.com`);
   - `[3]` — Запуск с **Localtunnel**;
   - `[4]` — Полная пересборка проекта.

---

### Для macOS и Linux:
Откройте терминал в папке проекта и выполните:
```bash
./start-macos.sh
```
*(Если система запросит права на запуск: `chmod +x start-macos.sh`)*.
Скрипт выполнит сборку, откроет браузер и предоставит выбор режима запуска (локально или через туннель).

---

## 3. Ручной запуск через терминал

Если вы предпочитаете запускать команды вручную:

```bash
# 1. Установка зависимостей (только в первый раз)
npm install

# 2. Сборка проекта
npm run build

# 3. Запуск сервера
npm start
```
Сервер запустится на адресе **`http://localhost:3000`** и будет доступен на всех сетевых интерфейсах (`0.0.0.0:3000`).

---

## 4. Организация удалённого доступа через туннель

Сервер и сборка приложения уже предварительно настроены для работы за любыми туннелями:
- Разрешены все внешние хосты (`allowedHosts: true`);
- Включена поддержка прокси-заголовков (`trust proxy: true`);
- Настроен `CORS` для любых доменов.

Вы можете выбрать любой удобный инструмент туннелирования:

### Вариант А: Cloudflare Tunnel (Рекомендуется — бесплатно, стабильно, без регистрации)
В отдельном окне терминала в папке проекта выполните:
```bash
npm run tunnel:cloudflare
# или напрямую:
npx cloudflared tunnel --url http://localhost:3000
```
В консоли появится ссылка вида:
`https://random-name-here.trycloudflare.com`
Отправьте эту ссылку председателю или откройте её на смартфоне — приложение будет доступно с шифрованием HTTPS.

---

### Вариант Б: Localtunnel (через npx без установки)
```bash
npm run tunnel:localtunnel
# или напрямую:
npx localtunnel --port 3000
```
Вы получите ссылку вида:
`https://friendly-name.loca.lt`

---

### Вариант В: ngrok
Если у вас установлен ngrok:
```bash
ngrok http 3000
```

---

## 5. Доступ по локальной сети Wi-Fi (без интернета)
Если ваши устройства (ноутбук, планшет, телефон) подключены к одному и тому же Wi-Fi роутеру в ДТСН или офисе:
1. Посмотрите локальный IP-адрес компьютера (сервер выводит его в консоль при старте, например: `http://192.168.1.45:3000`).
2. Введите этот адрес в браузере телефона — приложение откроется напрямую без сторонних сервисов.

---

## 6. База данных и автономность
- Все кадастровые участки, узлы учёта воды, задвижки, ЛЭП, камеры и контуры сетей сохраняются локально в хранилище браузера (`LocalStorage`) и восстанавливаются при каждом открытии.
- Вы можете в любой момент выгрузить базу участков в Excel кнопкой **«Экспорт в Excel»** или загрузить через окно **«Импорт / Экспорт»**.
